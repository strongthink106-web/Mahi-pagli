# Maisha — A Little Universe of Love

A Bengali-first, seven-chapter romantic keepsake made for Maisha. The experience uses original SVG/CSS artwork, cinematic ambient motion, soft rose/plum/candlelight colors, and thoughtful interactions.

## Experience map
1. `index.html` — A cinematic opening, written as a love note
2. `wishes.html` — Six wishes and gentle messages
3. `letter.html` — An interactive sealed love letter
4. `memories.html` — Four illustrated romantic moments (illustrations, not fabricated personal photos)
5. `garden.html` — An interactive garden where each touch blooms a flower
6. `cake.html` — A celebratory cake and candle interaction
7. `finale.html` — A personal first-love dedication and user-triggered celebration

## Design
- Deep plum, blush rose, warm champagne and soft lilac.
- Optional light theme, mobile-friendly chapter navigation and cinematic transitions.
- Cormorant Garamond, Hind Siliguri and DM Sans.
- Reduced-motion preference respected; motion can be switched off.
- No autoplay audio/video, trackers, API keys or server dependencies.
